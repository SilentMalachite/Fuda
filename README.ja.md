# fuda

[English](README.md) | 日本語

**fuda** は、ASD・ADHD・聴覚障害などがある人にも疲れずに使えることを目指した、完全オフラインのデスクトップ向け「やること・予定（スケジュール帳）・メモ・ボード（カンバン方式）」アプリです。

> **現在の状況:** 開発初期（**Phase 0: 技術の確認**）の段階です。本番用のクレート（`fuda-core` / `fuda-app`）は Phase 1 から作成予定で、現在は [`spike/fuda-spike`](spike/fuda-spike) にて技術検証を進めています。

---

## 概要

- **扱うのは「カード」1種類だけ:** すべてのデータは 1 種類の **カード** として扱い、いつも次の 5 つの場所のどれか 1 か所に置かれます。
  1. **とりあえず**（すぐ書いて置いておく場所）
  2. **やること**（チェックを付けて終わらせる場所）
  3. **予定**（決まった日・時刻にあることと、スケジュール帳の画面）
  4. **メモ**（終わりのないカードの場所）
  5. **ボード**（列に分けてカードを進める場所）
- **場所をまたぐ予定の見せ方:** 予定の画面（1日／1週間／1か月）では、日付を持つ「やること」や「ボード」のカードも、もとの置き場所を変えずにその日の欄へあわせて表示します。
- **音に頼らない「知らせの窓」:** 決めた時刻になると、いつも手前に出て・キーボードのフォーカスを奪わず・［わかった］を押すまで消えない **知らせの窓** で視覚的に知らせます。
- **完全ローカル・オフライン動作:** ネットワーク通信（クラウド同期・利用状況の送信・更新確認・祝日データの取得など）は一切行いません。

## 設計の決まり

[docs/SPEC.md](docs/SPEC.md) §2 に基づき、次の原則を守って作っています。

1. **1 画面に目的は 1 つ:** 主ボタンは 1 つに絞り、見出しでいまいる場所を明確にします。
2. **覚えさせない:** 入力は自動保存（保存ボタンなし）です。開き直すと前と同じ画面・カード・ウィンドウの大きさに戻ります。
3. **音に頼らない:** 音は既定でオフです。知らせは画面上の「知らせの窓」で出します。
4. **勝手に動かない:** 操作なしに並び順やスクロール位置を変えません。アニメーションは既定でオフ（オンでも 150ms 以下）で、知らせの窓は他アプリでの入力中もフォーカスを奪いません。
5. **時間で急かさない:** 自動で消える表示、時間制限、秒単位のカウントダウンは作りません。
6. **責めない:** 日付が過ぎたカードを赤や警告で出しません。未完了数のバッジ・連続記録・ポイントも作りません。
7. **いつでも取り消せる:** 削除はゴミ箱へ移すだけで、データを変える操作はすべて「元に戻す」（Ctrl/⌘+Z）できます。確認の問いかけは「ゴミ箱を空にする」だけにします。
8. **刺激を抑え、色だけに頼らない:** 透明・ぼかし・点滅を使いません。土日・祝日は文字で示し、カードの色にも色の名前を表示します。

## 現在の進捗

現在は本体クレート（`crates/fuda-core`・`crates/fuda-app`）の作成に先立ち、技術的なリスクを先に確かめる **Phase 0** を進めています。

[`spike/fuda-spike`](spike/fuda-spike) にて macOS 上で確認済みの項目:

- **0-1a:** workspace 構成、`slint` 1.19.0 と `rusqlite`（SQLite 3.54.1 同梱）の起動疎通
- **0-2:** BIZ UDPゴシック（Regular / Bold）の同梱表示、日本語・記号表示、固定幅による時刻数字の桁揃え
- **0-3a:** macOS での `LineEdit` / `TextEdit` 日本語入力（変換中の表示、変換確定 Enter で `accepted` が呼ばれないこと、複数行の改行）
- **0-4:** `Theme.font-base` の 4 段階切替（16px → 26px）に連動した文字・余白の追従、および `line-height-factor: 1.6` による行間指定

今後はドラッグ＆ドロップ（`0-5`）、日付・時刻の選択（`0-6`）、フォーカスを奪わない知らせの窓（`0-7`）、トレイ常駐（`0-8`）、および Windows 環境での確認（`0-1b`, `0-3b` 等）を進めていきます。

## 技術スタック

- **言語:** Rust (edition 2024)
- **UI:** [Slint](https://slint.dev/) `1.19.0`
- **データベース:** SQLite（`rusqlite` bundled、WAL モード）
- **同梱フォント:** BIZ UDPゴシック（SIL Open Font License 1.1）
- **祝日データ（Phase 3 で導入予定）:** 内閣府「国民の祝日」の CSV を UTF-8 に加工してアプリに同梱（実行時はオフライン）

---

## スパイクの動かし方

Rust（`stable` ツールチェーン）を用意したうえで、リポジトリ直下から次を実行します。

```sh
# Phase 0 技術確認ウィンドウを起動する
cargo run -p fuda-spike

# テストを実行する
cargo test --workspace

# コード整形と静的解析
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
```
