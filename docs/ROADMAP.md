# ROADMAP（作る順番）

- 1つのフェーズが終わるまで、次のフェーズに入らない。
- 各タスクは「1タスク = 1コミット」くらいの大きさ。大きすぎたら分けて、このファイルに書き足す。
- 終わったタスクは `[x]` にする。フェーズの **完了条件** を全部満たしたら、そのフェーズは終わり。
- 仕様は `docs/SPEC.md`。（ ）の中の § は SPEC の節。
- **Phase 5 が終わると、やること・予定・知らせのある手帳として毎日使い始められる**。その先（メモ・ボードなど）は、使いながら作る。

5. 予定の時刻を変えると、新しい時刻で知らせが出る（前の時刻では出ない）。
6. 音を出す設定がないことを確かめる（音は一切出ない）。
